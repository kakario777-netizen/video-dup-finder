# 중복 영상 찾기 (VideoDupFinder)

폴더나 FTP 안의 영상들을 실제 내용으로 비교해 중복을 찾는 윈도우 프로그램입니다. 파일 이름이나 날짜는 보지 않습니다.

## 찾는 중복
- **완전히 같은 파일**: 파일 해시로 비교
- **같은 영상**: 화질·해상도·코덱이 달라도, 화면 아래에 자막이 박혀 있어도, 화면 비율(검은 테두리)이 달라도, 좌우가 반전돼 있어도 찾음
- **포함된 영상**: 10분짜리 영상이 15분짜리 영상 안에 들어 있는 경우. 몇 분 몇 초 구간인지까지 표시
- **중간 편집본**: 중간을 잘라낸 영상
- **일부 구간 겹침**: 1분 이상 겹치는 경우
- **소리만 같음**: 참고용

판정은 화면 지문(장면별 dHash, 시간 순서까지 맞춰 봄)과 소리 지문(주파수 대역 변화)을 함께 씁니다.

## 깨진 영상 찾기 (옵션)
다음과 같은 영상을 찾습니다.
- 열리지 않는 파일, 0바이트 파일
- 끝부분이 없는 파일(다운로드 덜 됨), 중간에 끊긴 파일
- 재생 중 오류가 나는 파일
- 소리만 남은 파일

DRM이 걸린 파일이나 제조사 전용 형식은 깨진 영상과 구분해 '지원 안 됨'으로 표시합니다.

## 정리
- 지우지 않고 `중복자료` 폴더나 `깨진영상` 폴더로 **옮기기만** 합니다. 원래 폴더 구조를 그대로 유지합니다.
- 자막 파일은 같이 옮기기, 그대로 두기, 남길 영상 옆으로 옮기기 중에서 고를 수 있습니다.
- 폴더 안에 영상이 하나뿐이면 폴더째 옮길지 물어봅니다.
- '이동 기록' 탭에서 되돌릴 수 있습니다.
- 검사 결과는 `문서\중복영상 찾기 결과`에 엑셀과 json 파일로 자동 저장됩니다. 왼쪽 '저장된 검색 결과' 목록에서 다시 열 수 있습니다.

## 설치
[Releases](https://github.com/kakario777-netizen/video-dup-finder/releases)에서 `VideoDupFinder_Setup.exe`를 받아 실행하면 됩니다. 이후 업데이트는 프로그램 오른쪽 위의 '업데이트 확인'을 누르면 됩니다.
